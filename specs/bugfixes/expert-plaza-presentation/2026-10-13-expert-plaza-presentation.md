# 专家广场头像与卡片交互优化

## 1. 概述

专家缺省头像沿用龙虾图标，与专家广场的新视觉不一致。图片又被放入带底色的大容器，头像主体偏小。卡片仅标题和底部文字可打开详情，描述和中间留白缺少响应。

## 2. 用户场景

**Given** 用户浏览专家卡片。

**When** 点击头像、名称、描述、标签或卡片留白。

**Then** 打开同一详情弹窗。常驻的“召唤”按钮直接准备新会话草稿，不同时打开详情。

## 3. 功能需求

- 内置专家使用与三个现有示例头像同系列的中性机器人缺省图，主 Agent 和用户自建 Agent 保持原有显示。
- 兼容未安装目录中的空 icon，以及已安装 preset 被归一化成龙虾 SVG 的历史默认值；明确指定的其他 SVG 或专属图片继续展示。
- 远程专家头像失败时回退至本地底图，避免再次请求网络。头像仅改变显示，不改写持久化数据。
- 移除广场头像的外层底色和边框；列表、精选场景和详情分别直接显示 48、32、64 px 头像。
- 广场入口使用简洁的人物与星芒线性图标，在小尺寸下减少细碎轮廓。
- 每位专家增加一个独立的中英文示例问题，当前 70 位专家共 210 个示例。旧目录仍兼容，不把问题数量固定到客户端协议。

## 4. 实现方案

- `AgentAvatarIcon` 新增显式的专家回退选项。安装后通过 Agent 的 source 和 ID 判断，不按名称、icon 内容或 ID 名单猜测。共享的默认 Agent 图标常量保持原样。
- 广场直接启用专家回退；侧栏、输入框、专家选择器、Agent 管理与设置、子 Agent 卡片传递同一判断。选择器的自建图标选项保持不变。
- 卡片通过独立的整面详情按钮与上层召唤按钮承载操作，避免嵌套按钮，支持键盘焦点和 Enter / Space。卡片标签作为描述展示，标签筛选移至详情弹窗内。
- 默认头像为内置 image_gen 生成的原创图片，使用原有三张头像作风格参考；256×256 WebP 为 3,612 字节。原图与完整生成提示词保存在独立内容仓库的 `assets/` 下，应用只包含压缩资产。
- 示例问题维护在内容仓库 `experts/*.json`；构建本地 `2026-10-13.3` 用于验收，发布时再上传 CDN 并更新 Overmind。

## 5. 边界情况

| 场景 | 处理 |
|------|------|
| 自建 Agent 使用与预设相同的 ID 或名字 | source 为 custom，不启用专家底图 |
| 主 Agent 带 preset 来源 | 主 Agent ID 优先排除 |
| 专家已有专属图片或其他 SVG | 保留原图标；远程图片加载失败时用本地底图 |
| 旧目录只有两个示例 | 按原目录显示，更新下发后自然展示三个 |
| 点击卡片召唤按钮 | 只召唤一次，不触发详情 |
| 点击详情中的第三个问题 | 原样填入草稿，不自动发送 |

## 6. 验收标准

- 单元测试覆盖内置专家、主 Agent、自建 Agent、历史默认值和已有专属头像的隔离。
- 内容构建检查每位专家恰有三个不同的中英文示例，原有示例保留。
- 独立渲染验证整卡点击、召唤按钮、键盘操作、三条示例、加载失败回退和浅深主题。
- 修改文件通过 ESLint 与 TypeScript；测试脚本和截图仅存于仓库外，不占用用户键鼠。
