# 专家分类头像设计文档

## 1. 概述

### 1.1 问题与目标

旧 Agent 模板的图表、钢笔、文档等 SVG 默认头像与新版专家机器人风格不一致。新专家大量使用同一底图，难以在小尺寸下区分领域。本次为 15 个分类各配置一张头像，保留已有三个专属示例，并保证已安装专家的用户自定义头像不被覆盖。

## 2. 用户场景

### 场景 1：已有专家升级头像

**Given** 用户曾召唤内置专家，头像仍为出厂默认值。
**When** 用户加载新版专家目录。
**Then** 该专家使用目录中的分类图片，侧栏、专家选择器和设置页保持一致；名称、提示词、技能、模型与会话不变。

### 场景 2：用户已修改头像

**Given** 用户给已安装专家选择了其他 SVG 或图片。
**When** 目录刷新或应用重启。
**Then** 继续使用用户选择，主 Agent 和自建 Agent 也不参与自动升级。

## 3. 功能需求

- 每类一张 256×256 WebP，以明显的职业配饰和色彩区分，在 32 / 48 px 圆形裁切下可辨认；单张低于 20 KiB。
- 应用开发、小红书编辑、校园求职三个已有专属图片和 URL 保持不变。
- 专家目录中的旧 SVG 或图片加载失败时使用随客户端打包的中性机器人底图。
- 已安装专家只自动更新仍由预设管理的头像；用户选择的 SVG，包括龙虾图标，也必须保留。

## 4. 实现方案

### 4.1 内容与下发

内容仓库 `lobsterai-expert-store` 的 `assets/category-avatars.json` 保存分类图片文件和 CDN URL。构建时优先采用专家自身的 `icon`，未设置时继承所属分类图片，再输出 schema v1 目录；客户端无需内置分类图片表。原图、256×256 压缩图及完整生成提示词分别保存在 assets 的对应目录。

### 4.2 头像归属与兼容

SQLite `agents` 新增可空 `icon_customized` 字段：0 表示预设管理，1 表示用户选择，NULL 表示旧记录尚未明确标注。新增内置专家写入 0；自建和主 Agent 不参与管理。用户实际更换头像后写入 1，修改其他字段不改变归属。

对旧记录，以 `source=preset`、非主 Agent、稳定 preset ID 和历史默认值精确比对：与已知旧默认值相同，或仍为缺省龙虾头像，视为预设管理；其他已有图片或 SVG 保守视为用户选择。历史数据未记录用户曾重新选择同一个默认值的行为，无法还原这种意图；新增字段保证后续更改可明确识别。

`AgentManager.getExpertCatalog()` 在目录校验成功后，仅将有效图片 URL 写入仍受预设管理的已安装专家。数据层写入前再次检查归属，不修改其他配置，不触发 OpenClaw 重启。单个头像更新失败仅记录警告，不阻止目录展示。界面重新加载 Agent 列表，使新头像即时生效。

### 4.3 展示与编辑

统一使用 `usesManagedPresetAvatar()` 判断默认头像回退范围。完整目录的展示始终使用目录头像；用户安装后的实例由本地头像归属决定。设置页只在头像确实发生变化时提交 `icon`，避免仅修改名称时把旧值写回；选择器预览即时显示新选择。

## 5. 边界情况

| 场景 | 处理 |
|------|------|
| 主 Agent / 自建 Agent 的 ID 与 preset 相似 | 不升级、不改变回退策略 |
| 老模板实例改过名称或自动分配了其他 ID | 用 presetId 比对历史默认头像 |
| 用户改过头像后又选回旧默认 SVG | 保持用户归属，不自动替换 |
| 新图片获取失败 | 受管理专家显示内置默认机器人；用户头像保留原有回退行为 |
| 断网或专家被下架 | 保留本地头像，已有 Agent 继续可用 |
| 回滚专家目录 | 受管理图片可随有效旧目录变化，用户选择不变 |

## 6. 涉及文件

- `src/shared/agent/presetAvatar.ts`：头像归属和历史默认值兼容。
- `src/main/sqliteStore.ts` / `coworkStore.ts` / `agentManager.ts`：迁移、持久化和受控更新。
- Renderer Agent 类型、Redux 映射及头像消费组件：传递归属并统一展示。
- `lobsterai-expert-store`：分类映射、头像资产、生成提示词和目录构建。

## 7. 验收标准

- 15 个分类使用不同的图片 URL，原三个专属示例保持原样。
- 旧模板默认图标显示新底图，并可升级为分类图片。
- 用户修改头像后，刷新目录、重启应用均不覆盖；主 Agent 和自建 Agent 图标不变。
- 数据库迁移可重复执行，旧记录保持 NULL 以便保守识别；针对归属、刷新和展示的单元测试通过。
- 小尺寸预览、实际卡片、图片失败回退、亮暗主题验证通过。
