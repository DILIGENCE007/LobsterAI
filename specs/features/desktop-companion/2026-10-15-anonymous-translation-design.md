# 悬浮窗免登录翻译设计文档

## 1. 概述

### 1.1 问题/背景

悬浮窗翻译与朗读原来共用登录门槛，用户进行临时选词翻译时需要先登录。悬浮窗功能尚未正式发布，本次在现有界面和主进程能力上调整翻译准入。

### 1.2 目标

仅悬浮窗翻译支持未登录使用；朗读、总结、解释、润色、追问和继续会话保留原有登录引导。匿名时按安装设备计算每日额度，登录后按账号计算，各自独立，每日最多 1000 次。服务端保留设备分钟防刷限制。

本文只记录端侧设计和验收，不包含服务接口协议、上游地址、签名规则或服务凭据。

## 2. 用户场景

### 场景 1：未登录快速翻译

**Given** 用户未登录，选中了待翻译文本。

**When** 在悬浮窗点击翻译。

**Then** 直接展示流式译文，允许切换语言、复制和重新翻译，不弹出翻译登录拦截。

### 场景 2：翻译后使用其它工具

**Given** 未登录用户已看到译文。

**When** 使用朗读、追问或总结等功能。

**Then** 展示对应功能的原有登录引导，同时保留译文及翻译操作能力。

### 场景 3：登录、退出和额度切换

**Given** 用户已使用一部分设备翻译额度。

**When** 登录后翻译，再退出登录。

**Then** 登录时消耗账号额度，退出后恢复设备的剩余额度；身份切换清理旧请求和结果。

## 3. 功能需求

### FR-1：限定匿名入口

仅翻译放开匿名准入；禁止把整个语言工具面板或通用问答能力一并放开。

### FR-2：身份与额度

复用主进程已有的持久安装标识。退出登录不重置该标识。按当前工具查询额度；翻译和朗读的额度状态分别维护，迟到的查询不能覆盖较新结果。

### FR-3：独立错误状态

翻译、朗读和追问的登录要求分别处理。追问触发登录提示后，翻译语言选择、复制和重新翻译仍可操作。日额度耗尽明确提示每日 1000 次限制，频率超限提示稍后重试。

### FR-4：兼容已有认证

已登录请求沿用现有认证与刷新逻辑，认证失败不能悄悄改用设备额度。未登录翻译不触发账号刷新。暂未升级的服务无法支持匿名时展示不可用提示。

## 4. 实现方案

### 4.1 主进程请求分流

`CompanionLanguageClient` 根据工具和当前登录状态决定准入，翻译使用持久安装标识；朗读继续要求有效登录状态。主进程注入已有身份读取和网络能力，渲染层不接触服务凭据。

### 4.2 IPC 与界面状态

配额查询增加工具选择，控制器与 preload 同步透传。`useLanguageTools` 合并当前工具额度并跟踪查询版本；重置、取消、身份变化或卸载后丢弃旧结果。`LanguageToolsSurface` 将翻译登录错误与其它工具错误分开处理。

### 4.3 上游可替换性

供应商适配由服务侧负责，端侧继续消费现有的翻译事件和额度模型。供应商变化无需改动翻译交互。

## 5. 边界情况

| 场景 | 处理方式 |
| --- | --- |
| 未登录切换到朗读、总结或追问 | 展示原登录引导，翻译仍可用 |
| 身份切换时翻译未结束 | 取消旧请求，忽略迟到事件，清理旧结果 |
| 配额查询失败 | 不以查询失败替代实际翻译结果，由实际请求反馈状态 |
| 配额查询晚于翻译完成 | 忽略旧查询，避免覆盖完成事件中的新额度 |
| 登录凭据过期 | 保持原认证流程，不回退匿名计数 |
| 达到日额度或分钟限制 | 展示对应中文/英文提示，并保留重试入口 |
| 清空应用数据或重装 | 安装身份可能重建；不宣称其为不可伪造硬件身份 |

## 7. 验收标准

1. 未登录从悬浮窗完成真实翻译，可复制、切换语言和重新翻译。
2. 同一未登录会话的朗读、总结和追问仍显示登录引导；引导不锁住翻译操作。
3. 登录前后使用独立额度，退出登录保留安装身份。
4. 日额度和频率限制提示正确，不重复发起翻译请求。
5. 相关单元测试、改动文件 ESLint、Electron 编译和 renderer 构建通过。

### 7.1 已完成的自动化验证

2026-10-15 初次实现验收：相关 Vitest 24 项通过；改动 TS/TSX 的 ESLint 零警告，Electron TypeScript 编译及生产构建通过。浏览器受控组件验证覆盖译文展示、追问登录引导、语言切换、朗读登录引导和每日 1000 次提示。

同步 `release/2026.10.13` 基线 `8f8c1b8fb` 后，24 项相关测试、9 个改动 TS/TSX 文件的 ESLint、Electron 编译和 renderer TypeScript 检查再次通过。生产构建复跑在 Vite 阶段应需求方要求停止，以降低本机负载；待负载允许后补跑 `npm run build`。

### 7.2 Electron 真实环境验收

2026-10-15 使用独立应用数据目录连接本地测试服务和真实翻译供应商，运行实际 Electron 主进程、preload 与构建后的悬浮窗组件。通过调试通道驱动控件，没有模拟系统鼠标键盘。

| 项目 | 结果 |
| --- | --- |
| 未登录翻译 | `Hello, world.` 返回 `你好，世界。`，剩余日额度从 1000 变为 999 |
| 未登录追问 | 展示「请先登录 LobsterAI，再使用此功能」及「去登录」；翻译语言选择、复制和重新翻译保持可用 |
| 语言切换 | 追问触发登录提示后仍可切换到英语，返回 `Hello, world.`，剩余额度变为 998 |
| 朗读 | 实际朗读窗口展示原有登录引导 |
| 总结、解释、润色、Ask | 通过实际 preload 与主进程均被登录校验拦截 |
| 登录后翻译 | 测试账号的独立额度从 0 次变为 1 次，真实返回「早上好。」；设备计数保持 2 次 |
| 退出登录 | 安装身份不变，恢复原设备剩余 998 次；账号计数仍为 1 次 |
| 每日上限 | 将隔离验收数据设为接近上限后，第 1000 次真实翻译成功；下一次显示每日 1,000 次及北京时间次日 00:00 重置提示 |
| 分钟限流 | 在验收设备达到分钟限制后，窗口显示「操作有些频繁，请稍等一分钟再试」，日次数不增加 |
| 限流恢复 | 等待实际窗口自然到期后，点击重试再次获得真实译文 |

以上核心验收通过，断言和 8 张实际窗口截图保存在本地 `sandbox/translation-acceptance/electron/`。选词文字通过现有浮窗入口注入，本轮没有操作其它桌面应用的原生选词或检查浮窗跟随定位。限额边界使用隔离验收数据准备条件，再通过真实窗口触发请求，未连续发起 1000 次翻译。
